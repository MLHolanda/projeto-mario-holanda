# Identidade Visual — Logo Mário Holanda

## 1. Direção aprovada

A marca nasce do monograma **MLH**, integrado a uma árvore.

O conceito visual aprovado é:

**M → tronco/árvore ← H**

- A parte direita do **M** funde-se ao tronco.
- A parte esquerda do **H** funde-se ao mesmo tronco.
- O **L** não deve aparecer como uma letra independente.
- O sistema de raízes representa a continuidade, origem e ancestralidade.
- A árvore representa crescimento, conhecimento, desenvolvimento e trajetória.
- A seta ascendente representa crescimento, evolução, aprendizado e futuro.
- O símbolo deve parecer uma construção de identidade, e não uma ilustração genérica produzida por IA.

## 2. Princípio fundamental

O símbolo deve funcionar como **uma única estrutura visual**.

Não devem existir espaços visuais entre:
- M e tronco;
- H e tronco.

As hastes internas que fazem essa ligação deixam de ser percebidas como letras independentes e passam a fazer parte do tronco.

## 3. Sistema de marca previsto

A identidade deverá possuir, no mínimo:

1. **Símbolo principal** — árvore + MLH integrado.
2. **Logotipo** — símbolo + MÁRIO HOLANDA.
3. **Assinatura completa** — símbolo + MÁRIO HOLANDA + “UM CAPÍTULO DE CADA VEZ”.
4. **Símbolo reduzido** — para tamanhos pequenos.
5. **Favicon** — versão otimizada para 16–48 px.
6. **Versão monocromática positiva**.
7. **Versão monocromática negativa**.
8. **Versão para fundo claro**.
9. **Versão para fundo escuro**.
10. **Versão comercial** — preparada para projetos derivados, incluindo Mário Holanda Ofertas.

## 4. Regra de redução

Antes de considerar a identidade finalizada, o símbolo deverá ser testado em tamanhos pequenos.

A prioridade é preservar:
- leitura do conjunto;
- reconhecimento do símbolo;
- percepção do M/H integrado;
- árvore;
- seta;
- raízes.

Detalhes decorativos que desaparecerem em redução não devem ser considerados elementos essenciais da marca.

## 5. Vetorização

O arquivo mestre deverá ser **vetorial**, sem depender de uma imagem rasterizada incorporada.

Formato principal:
- SVG editável.

Formatos derivados:
- PDF vetorial;
- PNG com transparência;
- JPG para usos que exigirem fundo;
- possibilidade de EPS para fornecedores gráficos, se necessário.

O SVG mestre será a fonte oficial para os demais formatos.

## 6. Cores — direção inicial

A identidade parte de duas cores principais:

### Verde — crescimento / vida / conhecimento
Direção sugerida:
`#0F766E`

### Dourado — valor / conquista / evolução
Direção sugerida:
`#C9A227`

Como cor estrutural de apoio:
### Azul profundo
`#0B1F3A`

O azul não precisa aparecer obrigatoriamente dentro do símbolo. Ele pode funcionar como cor institucional do ecossistema digital.

### Regra

Não depender de gradientes, brilhos ou efeitos 3D para reconhecer a marca.

A marca deverá continuar funcionando em cores chapadas.

## 7. Critério de originalidade

A aparência final não deve depender de:
- brilho metálico;
- textura;
- efeitos tridimensionais;
- excesso de folhas;
- raízes excessivamente detalhadas;
- elementos decorativos genéricos.

Esses efeitos podem existir em aplicações especiais, mas não fazem parte da estrutura essencial do símbolo.
